# Groq ChromaDB RAG - Complete Guide

## Introduction
This is a Retrieval Augmented Generation (RAG) project built using **Groq API** and **ChromaDB**.

## Features
- 🚀 Super fast answers using Groq LPU
- 📚 Supports `.txt`, `.pdf`, `.md` files
- 💾 Persistent vector storage with ChromaDB
- 🔍 Semantic search with `all-MiniLM-L6-v2`
- ⚡ FastAPI + Swagger UI at `/docs`
